# Yatube API (Проект управления публикациями)

Yatube API — это REST API для социальной сети блогов Yatube, разработанный на базе Django REST Framework. Проект предоставляет интерфейс для публикации постов, управления тематическими группами и комментирования записей.

## 🛠️ Технологический стек
- **Python** 3.12
- **Django** 5.1.1
- **Django REST Framework** (DRF)
- **TokenAuthentication** (встроенная система токенов DRF)
- **SQLite3**

## 🚀 Как развернуть проект локально

1. **Клонируйте репозиторий на свой компьютер:**
   ```bash
   git clone https://github.com
   cd api_yatube
   ```

2. **Cоздайте и активируйте виртуальное окружение:**
   - **Для Windows:**
     ```bash
     python -m venv env
     .\env\Scripts\Activate.ps1
     ```
   - **Для macOS / Linux:**
     ```bash
     python -m venv env
     source env/bin/activate
     ```

3. **Обновите pip и установите все необходимые пакеты из requirements.txt:**
   ```bash
   python -m pip install --upgrade pip
   pip install -r requirements.txt
   ```

4. **Выполните миграции базы данных:**
   ```bash
   python manage.py migrate
   ```

5. **Создайте учетную запись суперпользователя (администратора):**
   ```bash
   python manage.py createsuperuser
   ```

6. **Запустите локальный сервер разработки:**
   ```bash
   python manage.py runserver
   ```
   Сервер будет доступен по адресу: `http://127.0.0`

## 🔒 Права доступа и аутентификация
В проекте настроена глобальная защита эндпоинтов. Доступ к API предоставляется **только аутентифицированным пользователям** (за исключением стандартной админки Django).
- **Чтение данных** (`GET`) доступно любому авторизованному пользователю.
- **Изменение и удаление данных** (`PUT`, `PATCH`, `DELETE`) разрешено **только автору** контента. При попытке отредактировать чужой пост или комментарий API возвращает код `403 Forbidden`.

## 📋 Примеры запросов и ответов

### 1. Получение токена авторизации
Передайте логин и пароль созданного пользователя для генерации уникального токена.
- **Эндпоинт:** `POST /api/v1/api-token-auth/`
- **Тело запроса (JSON):**
  ```json
  {
      "username": "katerina",
      "password": "YourStrongPassword123!"
  }
  ```
- **Ответ сервера (200 OK):**
  ```json
  {
      "token": "9944be6e16ca6025213271716fb22527"
  }
  ```

> ⚠️ **Важно:** Все последующие запросы должны содержать HTTP-заголовок авторизации:
> `Authorization: Token 9944be6e16ca6025213271716fb22527`

### 2. Добавление новой публикации
- **Эндпоинт:** `POST /api/v1/posts/`
- **Тело запроса (JSON):**
  ```json
  {
      "text": "Вечером собрались в редакции «Русской мысли», чтобы поговорить о народном театре.",
      "group": 1
  }
  ```
- **Ответ сервера (201 Created):**
  ```json
  {
      "id": 1,
      "text": "Вечером собрались в редакции «Русской мысли», чтобы поговорить о народном театре.",
      "pub_date": "2026-09-08T12:13:46.336979Z",
      "author": "katerina",
      "image": null,
      "group": 1
  }
  ```

### 3. Добавление комментария к посту
- **Эндпоинт:** `POST /api/v1/posts/1/comments/`
- **Тело запроса (JSON):**
  ```json
  {
      "text": "Отличный проект театра! Ждем открытия."
  }
  ```
- **Ответ сервера (201 Created):**
  ```json
  {
      "id": 1,
      "author": "katerina",
      "post": 1,
      "text": "Отличный проект театра! Ждем открытия.",
      "created": "2026-09-08T12:15:22.104231Z"
  }
  ```

### 4. Получение списка тематических групп
- **Эндпоинт:** `GET /api/v1/groups/`
- **Ответ сервера (200 OK):**
  ```json
  [
      {
          "id": 1,
          "title": "Математика",
          "slug": "math",
          "description": "Посты на тему математики"
      }
  ]
  ```
